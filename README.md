# 144Hz Unlocker Global

amoled / liquid-glass redesign of the OriginOS 144 Hz unlocker, based on the functionality published in `ewfawfasdf/VivoIQOO144FPSUnlocker`.

## changes

- AMOLED-first liquid glass interface
- animated, tactile Material switch
- Telegram button: https://t.me/rommy_apps
- Android 16 / API 36 target
- keeps the OriginOS `gamecube_frame_interpolation_for_sr` 144 Hz toggle
- GPL-3.0 project; original work is credited above

The unlock only removes an OS-level refresh-rate restriction. It does not guarantee that a game can render 144 FPS.
